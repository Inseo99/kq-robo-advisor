# Rule: Creating a Product Requirements Document

## Goal

KQ Quant Tool에 새 기능을 추가할 때, 사용자의 아이디어를 명확하고
구현 가능한 PRD(Product Requirements Document)로 변환한다.

## When to Use

다음과 같은 경우에 이 프롬프트를 사용한다:

- 새 분석 기능 추가 (예: 새 팩터, 새 시각화)
- 새 데이터 소스 통합 (예: KRX, ECOS API)
- 백테스트 또는 자산배분 전략 추가
- UI 큰 변경 (탭 추가, 레이아웃 개편)

## Process

1. 사용자의 기능 설명을 분석한다.
2. **코드를 작성하지 않는다.**
3. 모호하거나 누락된 사항을 질문한다.
4. 답변을 바탕으로 PRD를 작성한다.
5. PRD를 `tasks/prd-[feature-name].md` 형식으로 저장한다.

## Clarifying Questions (퀀트 프로젝트 특화)

다음을 확인한다:

### 기능 정의
- 해결하려는 문제는 무엇인가?
- 누가 사용할 것인가? (본인 / 팀원 / 발표 평가자)
- 발표에서 강조할 차별점인가? (그렇다면 학술적 변호 가능성 검토)

### 데이터
- 필요한 데이터는 무엇인가? (가격, 재무, 매크로, 외부 API)
- 데이터 출처는? (엑셀 / yfinance / KRX / FnGuide)
- 데이터의 시간 범위와 빈도는?
- 결측치 / 상장폐지 / 거래정지 처리는?

### 알고리즘 / 모델
- 어떤 알고리즘을 쓰는가? (규칙 기반 / ML / 통계)
- 학습 데이터와 검증 방법은?
- 데이터 누수 (look-ahead bias) 방지책은?
- 표본 크기 (분기 / 일별 / 종목 수)는 충분한가?

### UI / 시각화
- 결과를 어디에 표시할 것인가? (어느 탭 / 새 탭)
- 어떤 차트 또는 표가 필요한가?
- 사용자 인터랙션이 있는가? (드롭다운, 필터, 클릭)

### 범위
- 이번에 반드시 만들 것은? (Must have)
- 이번에 안 만들 것은? (Out of scope)
- 미래에 확장할 가능성은?

### 검증
- 성공 기준은? (정확도, 응답 속도, 시각적 품질)
- 테스트 방법은?
- 발표에서 받을 예상 질문은?

## PRD Structure

```
# [Feature Name]

## 1. Overview
간단한 개요 (1-3 문장)

## 2. Problem Statement
현재 문제 / 한계

## 3. Goals
이 기능이 달성할 목표 (번호 매김)

## 4. Target Users
대상 사용자

## 5. User Flow
사용자 흐름 단계

## 6. Functional Requirements
- FR-1.1: ...
- FR-1.2: ...
- FR-2.1: ...

## 7. Non-Functional Requirements
- NFR-1: 성능
- NFR-2: 보안
- NFR-3: 호환성

## 8. Data Requirements
필요한 데이터, 출처, 처리 규칙

## 9. Edge Cases
- EC-1: ...
- EC-2: ...

## 10. Out of Scope
이번에 안 할 것들 (명확히)

## 11. Acceptance Criteria
체크박스 형태로 검증 가능한 항목

## 12. Open Questions
미확정 사항 + 추천 의견

## 13. 작업 순서 (구현 단계)
Task list 생성을 위한 큰 그림
```

## Important Rules

- **요구사항에 없는 기능을 임의로 추가하지 않는다.**
- 기술 구현보다 사용자 요구를 먼저 정의한다.
- 각 요구사항에 고유 번호를 붙인다.
- 검증 가능한 수용 기준을 작성한다.
- 모호한 요구사항을 추측으로 확정하지 않는다.
- **이번 개발 범위에서 제외되는 내용을 명시한다.**
- 퀀트 프로젝트의 데이터 누수 방지를 검토한다.
- 발표에서 받을 학술적 질문을 미리 정리한다.

## KQ Quant Tool 프로젝트 컨텍스트

이 프로젝트는 다음을 이미 갖추고 있다:

- KOSPI + KOSDAQ 3,070 종목 (엑셀 데이터)
- 12년 분기 재무 데이터 (FnGuide)
- 12년 일봉 OHLCV (수정종가 + 실제종가)
- PER/PBR/EPS/BPS/배당 메트릭
- 매크로 (GDP, 금리, 환율)
- 핵심 기능: 스크리너, ETF 자산배분, 백테스트, 로보신호, AI 시장 국면

새 기능은 위 기존 자산을 활용하는 방향으로 설계한다.
새 데이터 소스가 필요하면 PRD에 명시한다.
