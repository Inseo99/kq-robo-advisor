# backtest-ksj — 모멘텀 20종목 워크포워드 백테스트

김성종 파트 백테스트. 자체 완결형(원본 서버 코드와 독립)으로, `data/cache`의 수정주가·분기 재무·KODEX200만 사용한다.

## 실행

```bash
# 저장소 루트의 가상환경 사용
cd backtest-ksj
../.venv/Scripts/python.exe run.py
```

결과는 `results/`에 생성된다. 최초 실행 시 가격 패널(수정종가/수정시가)과 시총 히스토리를
`data/`에 parquet으로 캐시하므로 재실행은 빠르다.

## 설계 요약 (2026-07-07 사용자 확정)

| 항목 | 값 |
|---|---|
| 유니버스 | Point-in-Time 시가총액 상위 **300** (KOSPI+KOSDAQ, 분기 시총 ffill; 현재 생존자 전용 리스트는 아님. 단, 원천 캐시 커버리지 한계 존재) |
| 종목선정 | 12-1 모멘텀(최근 1개월 제외 과거 11개월) 상위 **20**, 동일가중 |
| 실행 | 월간=월말평가→익월 첫 거래일 시초가 / 주간=금요일 종가평가→익영업일 시초가 (수정주가) |
| 거래비용 | 왕복 0.5% (편도 0.25% × 회전율 Σ\|Δw\|) |
| 현금수익 | 연 2% (월 2%/12, 주 2%/52 단리) |
| 벤치마크 | KODEX 200 (069500), 가격수익률 기준(분배금·세금 미반영) |

### 전략 6종
- **s1m / s1w**: 순수 모멘텀 (월간 / 주간)
- **s2m / s2w**: s1 + **t1 위험회피** — ①KODEX<9M MA, ②VIX>18.6, ③미국 신용스프레드 z(5M)>1.78 중 **2개 이상**이면 주식 0%
- **s3m / s3w**: s1 + **t2 추세추종** — KODEX 종가 > 10M MA → 100% 보유, 아니면 전액 현금
- 주간 위험회피 신호는 개월 창을 **주 단위 환산**: 9M→39주, 10M→43주, z 5M→22주

### 폴드 (walk-forward)
| 폴드 | IS | OOS |
|---|---|---|
| Fold1 | 2014~2018 | 2019~2020 |
| Fold2 | 2016~2020 | 2021~2022 |
| Fold3 | 2018~2022 | 2023~2024 |
| Fold4 | 2020~2024 | 2025~2026.5 |

4개 OOS는 연속 → **전체 OOS = 2019-01 ~ 2026-05**. 단, 전략 규칙은 사전 고정되어 있어
발표에서는 “OOS 통과”보다 “구간별 강건성 평가”로 표현한다.

## s2 (t1) 활성화 방법 — VIX·미국 신용스프레드 필요

t1 신호에 필요한 두 시계열은 저장소에 없어 **s2m/s2w는 기본 미실행**이다.
아래 CSV를 `backtest-ksj/data/`에 넣고 `run.py`를 재실행하면 자동 포함된다.

- `data/vix.csv` — 컬럼 `date,value` (일별 VIX; 예: CBOE VIX / FRED `VIXCLS`)
- `data/credit_spread_us.csv` — 컬럼 `date,value` (미국 신용스프레드; 예: ICE BofA US HY OAS / FRED `BAMLH0A0HYM2`)

파일명은 `data.py`의 후보 목록(`vix.csv`, `credit_spread_us.csv`, `BAMLH0A0HYM2.csv` 등) 중 하나면 인식된다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `config.py` | 모든 파라미터(유니버스/비용/임계값/폴드/전략) |
| `data.py` | 가격 패널 피벗·캐시, PIT 시총, KODEX200 접합, VIX/credit 로더 |
| `signals.py` | 12-1 모멘텀 선정, t1/t2 위험회피 게이트 |
| `engine.py` | 리밸런싱 루프 + 거래비용 + 현금 |
| `metrics.py` | CAGR/MDD/Sharpe/Calmar + 매매·비용 집계 |
| `run.py` | 오케스트레이션 + CSV/리포트 생성 |
| `results/report.md` | 최종 보고서 |

## ⚠️ 데이터 주의
저장소 가격 데이터는 **2025~2026 구간이 합성으로 크게 부풀려져** 있다(KODEX200·삼성전자 2025→2026 약 4~6배).
따라서 Fold4·전체 OOS의 절대 CAGR은 비현실적으로 높다. 해석은 **전략 간 상대 비교**에 둘 것.

## 방법론 주의

- 유니버스는 분기별 시총 이력에서 판정일 기준 상위 300을 뽑는다. 2014년/2018년 표본에
  2026년 현재 비활성 종목이 포함되는 것을 확인했으므로 현재 생존자 전용 리스트는 아니다.
  다만 상장폐지 전체 커버리지는 원천 `data/cache` 범위에 의존하므로 “생존편향 완전 제거”로
  과장하지 않는다.
- KODEX 200 벤치마크는 가격수익률 기준이다. 분배금 재투자 총수익률을 쓰지 않았으므로
  전략의 벤치마크 대비 초과수익은 일부 높게 보일 수 있다.
