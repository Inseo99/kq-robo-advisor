# Alpha Decay 적용 기준

## 목적

이 프로젝트에서 Alpha Decay는 "이 신호가 며칠 동안 돈을 벌어준다"는
확정 예측값이 아닙니다. 더 현실적으로는 다음 질문에 답합니다.

> 이 로보신호 또는 추천 배분을 언제 다시 점검해야 하는가?

따라서 고객 화면에서는 유효기간, 재점검 기간, 신호 신뢰도 보조 지표로
사용합니다.

## 한국시장 적용 규칙

한국시장 특성을 반영해 다음 규칙을 적용합니다.

- 시가총액 상위 종목 중심으로 먼저 검증한다.
- 상한가/하한가 근처의 일간 ±29.5% 움직임은 Alpha Decay 표본에서 제외한다.
- 매수 신호와 매도 신호를 같은 방향으로 섞지 않는다.
- 매수 신호는 이후 수익률을 그대로 본다.
- 매도 신호는 이후 수익률에 `-1`을 곱해 방어/회피 효과로 본다.
- 전체 기간을 한 번에 보지 않고 IS/OOS로 나눈다.
- 실제 신호 유효기간을 무작위 날짜와 비교한다.

## 현재 검증 결과

최근 실행 기준:

```text
python tests\validation_alpha_decay_is_oos.py --top 50 --n 100
```

OOS 2021년 이후 결과:

| 신호 | 실제 edge | 무작위 평균 | p-value | 해석 |
|---|---:|---:|---:|---|
| RSI 과매도 | +1.857% | +0.861% | 0.000 | 유효 |
| MACD 골든크로스 | +0.964% | +0.849% | 0.290 | 약함 |
| BB 하단터치 | +1.949% | +0.847% | 0.000 | 유효 |
| 전체 | +1.714% | +0.859% | 0.000 | 유효 |

이 결과는 Alpha Decay가 특히 매수형 과매도/하단터치 신호의
재점검 기간으로 쓸 근거가 있음을 뜻합니다.

## 현재 앱 적용 방식

단일 종목 로보신호:

- ATR 기반 추천 매수가, 목표가, 손절가를 표시한다.
- 활성 신호가 있으면 Alpha Decay 기반 유효기간을 표시한다.
- 반감기 추정이 불안정하면 peak day를 보수적인 대체 기준으로 쓴다.

추천 포트폴리오:

- 시장 국면은 공격/방어 배분 참고값으로 사용한다.
- Alpha Decay는 구성 자산별 로보신호의 재점검 기간으로 연결한다.
- 국면 자체는 아직 초과수익 엔진으로 확정하지 않는다.

## 다음 검증 과제

- KOSPI 대형주, KOSDAQ, ETF를 분리해 Alpha Decay 곡선을 비교한다.
- 매수형 신호와 매도형 신호를 분리해 p-value를 따로 본다.
- 거래비용과 슬리피지를 적용한 뒤에도 유효한지 확인한다.
- 추천 포트폴리오 탭에서는 "유효기간"과 "재점검 조건"을 고객용 문장으로 정리한다.
