# Methods 절 초안 (논문·캡스톤용)

Discussion 초안(docs/DISCUSSION_초안.md)과 한 쌍. 모든 절차는 리포지토리에서 재현 가능하다.

## 1. 데이터

거시 입력은 한국은행 ECOS·통계청 공표 계열을 사용한다: 분기 실질 GDP 성장률(계절조정
전기비), 소비자물가 상승률(전년동월비), 및 보조 시장 계열(국고채 3년·10년, 회사채
스프레드, 원/달러, KOSPI, 기준금리). 모든 지표는 발표지연(publication lag) 감사 표
(docs/macro_publication_lags.md)에 등록되며, 원칙은 "애매하면 lag를 늘린다"이다 —
CPI는 1개월, GDP는 속보·수정을 반영해 2개월의 보수적 lag를 적용한다. 자동 검증
(tests/validation_macro_pit.py)이 코드와 문서의 lag 일치를 대조한다. 2025년 이후 일부
계열에 합성 구간이 포함되며 해당 사실은 결과 해석 시 명시한다.

## 2. 국면 정의 (라벨 규칙)

국면은 성장·물가 2축의 4분면으로 정의한다: 골디락스(성장↑물가↓), 리플레이션(↑↑),
스태그플레이션(↓↑), 디플레이션(↓↓). 축 상태는 다음 규칙으로 판정한다.

- 성장 축: 분기 GDP 성장률이 직전 10년 창 내 중앙값을 상회하면 상(上).
- 물가 축(채택안 N5): 분기 CPI 상승률이 당시 유효한 한국은행 물가안정목표 T(t)
  (2016년 이후 2.0%, 이전 3.0%)를 초과하면 즉시 상(上), T(t)−0.5%p 미만이면 하(下),
  그 사이 구간에서는 직전 상태를 유지한다. 완충 폭 0.5%p는 한국은행 설명책임 제도의
  공표값이며, 목표치는 모두 각 적용 기간 개시 전에 공표되었다(시점 정합).

규칙에 자유 튜닝 파라미터는 없다 — 임계값(2.0/3.0/0.5)은 외생 공표값, 창 길이(10년)는
한국 경기순환 2사이클 포함 근거로 사전 선택되었고 5년·확장창 민감도를 병행 보고한다.

## 3. 워크포워드 라벨 생성 (look-ahead 차단)

매월 t의 라벨은 (t−120개월, t] 구간으로 절단된 데이터만 입력하여 산출한다 — 창 내
중앙값 등 모든 기준 통계가 창 내부에서만 계산되므로, 판정 함수의 내부 구조와 무관하게
미래 정보가 원천 차단된다. 라벨은 2011-01~2025-12의 180개월에 대해 생성하며,
2026년 이후는 라벨을 생성하지 않는 홀드아웃으로 보존하여 실운영 판정과의 비교군으로
사용한다(§6). 초기 구현에 존재했던 전 기간 통계 사용(look-ahead)은 자체 발견·교정되었다.

## 4. 사전 등록 프로토콜

라벨 규칙의 모든 변경 후보는 실행 전에 다음을 등록한다: 가설과 변경점, 채점 기준
(위기 앵커 6종 유지 / 창 일치율 하한 / 전환 수 상·하한 / 3개월 이하 구간 상한),
기각 조건. 후보별 시도는 1회로 제한하고 총 시도 횟수를 기록한다(다중 시도 통제).
설계 단계에서 입력 데이터를 열람한 경우 그 사실을 스크립트 헤더에 남긴다. 본 연구에서
실행된 시도는 7회(N1~N8, J1)이며 실행 전 설계 폐기 2건을 포함해 전 이력이
regime_next_실험로그.md에 기록되어 있다.

위기 앵커는 발표 이전에 고정된 6개 시점 판정이다: 2018-07(무역분쟁 — 위험 계열 유지),
2020-03(코로나 — 디플레이션 전환), 2020-12(회복 — 골디락스/리플레이션),
2021-09·10(인플레기 — 리플레이션/스태그플레이션), 2022-03(긴축 — 스태그플레이션).
앵커는 채점의 제약 조건이며 최적화 목표가 아니다 — 기존 채택본이 이미 6/6이므로
후보는 비열화만 요구받는다.

## 5. 평가 하네스

모든 후보는 동일 하네스로 채점한다: (i) 창 민감도 — 10년·5년·확장창 라벨의 상호
일치율(공통 구간 2011-01~2025-12), (ii) 위기 구간 채점 — 2008·2020·2022의 위험 계열
분류 여부, (iii) 구조 지표 — 전환 횟수, 3개월 이하 구간 수, 최장 구간, (iv) 사전 등록
앵커. 보조 검증으로 5개 연속 폴드(각 36개월)의 시기별 강건성 점검과, 후보 라벨로
분류기를 재학습했을 때의 나우캐스트 확률 경로 점검(판정 레이어 정보 보존)을 수행한다.
파라미터 선택이 개입하는 후보에는 경계 embargo를 둔 purged K-fold 선택 검증을 적용한다.

## 6. 홀드아웃과 실운영 대조

2026년 상반기는 라벨 미생성 홀드아웃이다. 대조는 두 방향으로 수행한다: (i) 사후
워크포워드 판정 — 각 월 t까지의 데이터로 규칙을 적용, (ii) 실운영 표시 판정 — 운영
로그(월 1회 기록)로 확보한다. 발표지연을 반영한 잠정 판정(provisional judgment)은
라벨 공백 구간의 화면 표시용으로 도입되었으며, 홀드아웃 채점에서 지속성 표시 대비
개선을 확인하였다(일치 2/6 → 3/6; 잔여 불일치는 GDP 공표 지연 2개월의 구조적 하한).

## 7. 2-트랙 라벨 체계

실시간 트랙(워크포워드, PiT)과 사후 확정 트랙(ex-post confirmed)을 구분한다. 확정
트랙은 위험 국면 사이에 고립된 3개월 이하 골디락스 구간을 사후 흡수한 시계열로,
NBER 기준순환일 판정과 같은 회고적 성격을 가진다. 확정 트랙은 비인과 시계열이므로
회고 분석과 시각화에만 사용하며 백테스트의 시점 매칭·실시간 판정·분류기 학습에는
사용하지 않는다(파일명에 _expost_ 접두를 강제).

## 8. 재현성

라벨 생성(scripts/regime_next_n5.py), 채점 하네스(scripts/walkforward_labels.py),
확정 트랙(scripts/regime_next_n8_confirmed.py), 잠정 판정(scripts/provisional_judgment.py),
HMM 벤치마크(scripts/research_hmm_comparison.py)는 모두 저장소에 포함되며 고정 시드로
결정적이다. 채택 라벨의 정본은 data/regime/labels.csv 하나이며, 구버전 생성기에는
덮어쓰기 가드가 있다.
