# PRD: AI 시장 국면 인식 (TabPFN + HMM + Alpha Decay 계층 모델)

## 1. 개요 (Overview)

KQ Quant Tool의 매크로 국면 분류를 **단순 규칙 기반에서 학습 기반 계층 모델**로 업그레이드한다.

- **1층**: TabPFN(또는 LightGBM 폴백)으로 현재 매크로 국면을 4국면 확률로 분류
- **2층**: HMM 방식 카운팅으로 국면 전환 매트릭스 및 평균 지속 기간 계산
- **3층**: 국면별 Alpha Decay 반감기 측정 (다음 단계에서 진행)

## 2. 문제 정의 (Problem Statement)

현재 시스템은 매크로 국면을 다음과 같이 분류한다:
```python
if GDP > 0.5% and 스프레드 > 0.5%:
    "골디락스"
elif ... # 단순 if-else
```

**문제점**:
- "AI 시장 국면 인식"이라 표시되어 있지만 실제로 AI가 아님
- 4국면 확률을 못 줌 (이분법적 분류)
- "다음 분기에 어떻게 될지" 예측 못 함
- 발표 시 "이게 어떻게 AI인가?" 질문에 답변 곤란

## 3. 목표 (Goals)

1. 실제 한국 매크로 12년 데이터(2014~2026)로 학습한 분류 모델 도입
2. 4국면을 **확률**로 출력 (예: 골디락스 78%, 리플레이션 15%, ...)
3. **다음 분기 국면 전환 확률** 표시
4. **전환 매트릭스** 시각화 (4×4)
5. 학술적 변호 가능 (TabPFN 또는 LightGBM, 둘 다 인용 가능 모델)

## 4. 대상 사용자 (Target Users)

- 본 프로젝트 발표를 받는 교수님
- 향후 프로젝트 결과물을 보는 평가자
- KQ Quant Tool 사용자

## 5. 사용자 흐름 (User Flow)

```
사용자: 브라우저 접속 → "AI 시장 국면" 탭 클릭
  ↓
서버: regime_model 학습 (서버 시작 시 1회, 약 3초)
  ↓
브라우저:
  1. 현재 국면 + 4국면 확률 막대그래프 표시
  2. 전환 매트릭스 heatmap 표시 (4×4)
  3. 다음 분기 전환 확률 표시
  4. 국면별 평균 지속 기간 표시
  5. 현재 매크로 지표 표시 (GDP, 스프레드, 환율)
```

## 6. 기능 요구사항 (Functional Requirements)

### FR-1. 모델 학습 (백엔드)
- **FR-1.1**: 서버 시작 시 `regime_model.HierarchicalRegimeModel`을 자동으로 학습
- **FR-1.2**: 학습 데이터는 `data_loader.load_macro()`의 결과 사용
- **FR-1.3**: TabPFN이 설치되어 있으면 우선 사용, 없으면 LightGBM 사용
- **FR-1.4**: 둘 다 없으면 규칙 기반으로 폴백 (에러 없이 동작해야 함)
- **FR-1.5**: 학습 실패 시 기존 `MACRO` 객체로 폴백 (서비스 중단 없음)

### FR-2. API 엔드포인트
- **FR-2.1**: 새 엔드포인트 `/api/regime_ai` 추가
- **FR-2.2**: 응답 JSON 구조:
  ```json
  {
    "current_regime": "골디락스",
    "model_type": "TabPFN" | "LightGBM" | "Rule-based",
    "current_features": {"gdp_growth": 0.98, "spread": 0.93, "usd_change": 0.0},
    "probs": {"골디락스": 0.78, "리플레이션": 0.15, "스태그플레이션": 0.05, "디플레이션": 0.02},
    "next_quarter": {"골디락스": 0.45, "리플레이션": 0.30, ...},
    "next_2quarters": {...},
    "duration_avg": {"골디락스": 4.2, "리플레이션": 3.1, ...},
    "transition_matrix": {
      "골디락스": {"골디락스": 0.5, "리플레이션": 0.3, "스태그플레이션": 0.1, "디플레이션": 0.1},
      ...
    },
    "regime_desc": {  // UI 표시용 — 색상, 자산 추천 등
      "골디락스": {"label": "성장↑·물가↓", "color": "#3fb950", "desc": "...", "best_assets": [...]},
      ...
    }
  }
  ```
- **FR-2.3**: 기존 `/api/macro` 엔드포인트는 유지 (하위 호환성)

### FR-3. 프론트엔드 — AI 시장 국면 탭
- **FR-3.1**: "AI 시장 국면" 탭 클릭 시 `/api/regime_ai` 호출
- **FR-3.2**: 현재 국면 배지 표시 (큰 글씨, 국면 색상)
- **FR-3.3**: 4국면 확률 막대그래프 (가로 막대, 색상 구분)
- **FR-3.4**: 전환 매트릭스 heatmap (4×4 표, 색상 강도로 확률 표현)
- **FR-3.5**: 다음 1분기 / 2분기 후 국면 전환 확률 표시
- **FR-3.6**: 국면별 평균 지속 기간 표시
- **FR-3.7**: 사용 모델 표시 ("Powered by TabPFN" 같은 배지)

## 7. 비기능 요구사항 (Non-Functional Requirements)

- **NFR-1**: 서버 시작 시 매크로 모델 학습이 5초 이내
- **NFR-2**: `/api/regime_ai` 응답 시간 200ms 이하 (학습된 모델 캐시)
- **NFR-3**: 모델 학습 실패해도 서버 시작 가능 (필수 기능 아님)
- **NFR-4**: 기존 모든 기능(스크리너, 백테스트, 로보) 영향 없음

## 8. 데이터 요구사항 (Data Requirements)

### 입력
- `data/주식 이외 데이터.xlsx` — GDP, 금리(국고1년/10년), 환율
- 최소 12분기 (3년) 이상 데이터 필요

### 출력
- 4국면 확률 분포 (합계 = 1.0)
- 4×4 전환 매트릭스 (각 행 합계 = 1.0)
- 국면별 평균 지속 기간 (분기 수)

## 9. 예외 처리 (Edge Cases)

- **EC-1**: 매크로 데이터 부족 (분기 < 4개) → 규칙 기반 폴백
- **EC-2**: TabPFN/LightGBM 모두 설치 안 됨 → 규칙 기반 폴백
- **EC-3**: 현재 국면이 한 번도 발생한 적 없는 경우 → 균등분포 25% 반환
- **EC-4**: GDP 또는 금리 데이터 컬럼명이 변경된 경우 → 빈 결과 반환, 에러 로그

## 10. 범위 외 (Out of Scope)

이번 작업에서 **하지 않을** 것들:

- ❌ 3층 (국면별 Alpha Decay 측정 통합) — 다음 단계
- ❌ 종목 선정에 국면 반영
- ❌ 자산배분 전략에 국면 반영
- ❌ 백테스트에 국면 가중치 추가
- ❌ XGBoost, CatBoost 등 다른 모델 추가
- ❌ 매크로 시트 다른 데이터(국채발행잔액, RP금리) 활용
- ❌ 시각화 라이브러리 추가 (Chart.js만 사용)
